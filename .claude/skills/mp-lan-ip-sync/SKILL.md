# 小程序真机调试地址同步

真机里的 `127.0.0.1` 指手机自己,所以 `dev.js` 必须写电脑的局域网 IP。家和公司切换后 IP 会变,旧地址没人接,表现为 503、超时或请求失败。

## 做法
1. 运行 `python -X utf8 .claude/skills/mp-lan-ip-sync/scripts/sync-lan-ip.py`。它会检测有默认网关且已连接的网卡的私网 IPv4(排除 VPN、Docker、虚拟网卡),只改写两个 `dev.js` 里的主机部分,保留端口和路径,然后探测 `8600` 是否可达。
2. 检测错了(多网卡)就加 `--ip <地址>`。只想看不想改用 `--check`。
3. 告诉用户:开发者工具重新编译或重新扫码;手机要和电脑在同一 WLAN,关掉手机上的代理和 VPN。
4. 报"不可达"时依次查:后端是否在跑(`netstat -ano | findstr :8600` 应是 0.0.0.0 监听)、防火墙入站规则对 java 是否放行当前网络类型(Public/Private)、路由器是否开了 AP 隔离或访客网络。

## 注意
- 只改 `dev.js`(develop 环境,真机调试用)。`test.js`/`prod.js` 是线上地址,不要动。
- `dev.js` 里的 IP 是个人环境值,提交前确认是否要带上;团队共用时建议不提交这类改动。
- 本地后端是否还连云上依赖,与这里无关,见 `sae-local-dev-link` skill。
